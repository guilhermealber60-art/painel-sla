# Painel SLA

Página simples para preencher, dia a dia, o SLA (OTD), o tempo de separação e (opcionalmente) os pedidos, e gerar a imagem de resumo para enviar no WhatsApp.

- Os dados acumulam mês a mês em `data/dados.json`.
- **Baixar imagem** / **Copiar imagem** / **Compartilhar** geram o PNG com o gráfico de evolução e o nível de serviço do mês.
- Para salvar e publicar os dados, clique em ⚙️ e cole um token do GitHub (fine-grained, restrito a este repositório, permissão *Contents: Read and write*). O token fica só no navegador de quem preenche. Sem token a página é somente leitura.
